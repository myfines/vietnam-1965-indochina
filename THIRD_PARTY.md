# Asset provenance

- EarthToHoI4 helpers: MIT; see vendor/LICENSE-EarthToHoI4. Geography: Natural Earth (public domain). Elevation: Mapzen Terrarium / USGS / NOAA.
- Focus structure was studied in [R8Ki0xx/millennium-dawn-asia-expansion](https://github.com/R8Ki0xx/millennium-dawn-asia-expansion), especially common/national_focus/05_vietnam.txt and 05_south_korea.txt. This campaign uses original scripts and prose. Its focus art is not copied from that mod or its Workshop dependencies.
- Park Seicheng is fictional. His painted portrait is original, generated for this project with OpenAI image generation on 2026-10-18. The faction flags are original.
- Historical portrait catalog: portrait-catalog.json. Provider: [Cold War Iron Curtain](https://github.com/Cold-War-Iron-Curtain-Dev-Team/ColdWarIronCurtain), development-branch, Cold War Iron Curtain/gfx/leaders. No clear license for redistribution of those finished portraits was located. They are downloaded directly into the ignored runtime folder for local use and are not bundled in this public repository. This is not a public-domain claim for that artwork. Historical Commons-photo downloads were attempted but failed on the local connection; they are not used in the build.
- No game installation files, novel text, credentials, saves or machine logs are distributed. Base-game compatibility files are generated from the user-owned installation. The novel is used only as inspiration; the mod does not distribute the novel or claim its fictional events are historical.
- Focus artwork references locally installed base-game textures: the original catalog has 17 bindings, and the expanded semantic catalog has 52, with 47 distinct painted textures actually assigned across 454 nodes. See `native-art-catalog.json` and `focus-art-manifest.json`; no Paradox textures are redistributed. The old Font Awesome badges were removed. The Ultimate-HOI4-GFX toolkit and friend mod were examined as references, but no third-party icon pack was bundled.

## 0.6 additions

Four additional CWIC portraits (Pol Pot, Nguyen Khanh, Tran Van Hai and Nguyen Ngoc Loan) are fetched only into the local runtime. The Phu Quoc council uses an original faction flag. All eight generated faction flag sets are original programmatic artwork. New dialogue is original adaptation; neither the private novel nor TNO script/art is distributed.

The command dossier background and prestige bar are original geometric artwork generated by `tools/build_command_interface.py`. The interface references the same runtime-only portraits; the public package contains no additional historical portraits. The optional layout renderer requires the local Windows Microsoft YaHei font and does not distribute that font.

## 0.7 additions

All 80 authored national spirits have explicit icon bindings. `spirit-art-manifest.json` maps them to 13 native-art subjects. The installer resizes locally owned goal artwork into 64×64 spirit icons inside the ignored runtime directory; neither source pixels nor derived icons are bundled publicly. Focus art now uses 47 distinct native textures across 454 nodes after the Park-line rewrite. New dialogue and fictional war-credit choices are original adaptations, not quoted novel text.

## 0.7.1 additions

There are now 85 authored spirits and 15 locally hydrated icon subjects. ROK and ROC mission icons use the locally installed `gfx/flags/KOR_democratic.tga` and `gfx/flags/CHI_neutrality.tga`. The installer also uses the local ROK flag for Park's expeditionary faction at all flag sizes. These native flags and derived icons are not redistributed in this repository. Korean/Taiwanese military participation is an alternate-history mod configuration, not a claim that these fictional formations existed historically.
