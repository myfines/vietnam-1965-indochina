# Vietnam 1965 — Indochina Theater

钢铁雄心 IV 越南战争独立战区，当前版本 **0.3.0**，目标游戏 **1.19.x**。地图覆盖越南、柬埔寨及周边背景地带：47州、1575省份单元、73个城市和基地。1965年10月28日开局，南北越交战。

## 安装和选择挂载

需要正版游戏、本机 Python 3.10+。下载本仓库 ZIP 并解压，或 git clone。第一次运行：

    python -m pip install -r requirements.txt
    python tools/install.py

自动识别失败时，指定游戏目录：

    python tools/install.py --game "F:\SteamLibrary\steamapps\common\Hearts of Iron IV"

双击 **manage-mod.cmd** 打开选择菜单：

只想玩游戏：安装完成后直接双击 **start-vietnam.cmd**，它会自动挂载、启用并启动游戏，无需输入菜单编号。入口会检查日志，确认地图和1965年日期实际加载；失败会显示错误。若已有游戏运行，请先保存并退出。

1. **Mount**：注册本地模组，供启动器发现，不改变启用列表。
2. **Enable**：只启用本模组，并备份原启用列表。独立地图不应与其他地图模组混用。
3. **Disable**：停用并恢复先前列表；若用户已另改列表，仅移除本模组。
4. **Unmount**：取消本地注册，保留下载内容和游戏文件。
5. **Status**：查看挂载、启用状态。
6. **Enable and launch**：只启用本模组并直接启动游戏，避免启动器播放集覆盖启用列表。

注册名为 **Vietnam 1965 Public**。挂载后重启 Paradox 启动器，选择该本地模组；启动器选择其他播放集会覆盖直接启用设置。安装和切换后开新局，旧存档需要原模组组合。

## 国策内容

共40项，分属三国专属国策树：

| 国家 | 国策分支 |
|---|---|
| 南越 | 7项建设基础；朴正熙援越协议 → 朴世诚与归仁预备队 → 战报宣传 → 日海军需 → 特战司网络 → 境外筹划维新；西贡派系摊牌 → 广播通讯／军费协商 → 戒严／文官监督；小道封锁行动 |
| 北越 | 7项建设基础；胡志明小道 → 丛林中转站 → 后方潜伏网络 → 分散南方守备 |
| 柬埔寨 | 7项建设基础；西哈努克中立路线 → 边境运输通道 → 西哈努克港建设 |

“建设基础”包括战区司令部、修复交通、军械工坊、部队整训、补给计划、行政合作、后方生产。

## 政治与战争机制

- 完成南越“西贡派系摊牌”后，在决议中花政治点争取西宁、边和、头顿、美萩驻军。支持60以上才计入结果；反对派每周削弱支持。
- 发动政变：3个以上支持州则和平成功，1至2个则西贡—头顿军政委员会引发内战，零个则失败。玩家继续控制原国家。
- 全国戒严降低支持流失，但增加政治和生产负担；广治州抽象代表非军事区，不执行戒严。
- 北越运输网每月有机会积累渗透准备；可消耗政治点、准备与运输能力，在邦美蜀、大叻或西宁后方生成真实低装备部队。南越可截断运输，袭击冷却45天。
- 韩国不在本地图内，朴正熙与朴世诚政治线通过境外事件呈现。受小说启发，部分事件为可提前展开的架空改编。
