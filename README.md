# Vietnam 1965 — Indochina Theater

钢铁雄心 IV 独立越南战区，版本 **0.6.0**，目标游戏 **1.19.x**。47州、1575省份单元、73处城市和基地；1965年10月28日开局。本作采用小说启发的架空势力配置，军区和远征军在地图上独立管理，并非史实行政疆界复刻。

## 怎么玩

本轮指挥机制更新：23段主事件改为短摘要。中央可逐个设立军区，再将完整控制的南方地区逐块划归；军区以指挥协定隶属中央。中央威望低于30、军区忠诚低于25时可以拒令、要求改组或起兵。朴前期可经营人脉、组建直属部队，后期要求接管南越。具体剧情依据和已实现边界见 [剧情与指挥整理](design/novel-plot-and-command.md)。此轮请从新游戏验证，旧版外交傀儡军区的存档未测试。

新增11项和原有29项引擎检查通过；两个月扩展场景仍有既知的AI战区首都断言。见 [本轮验证](VALIDATION_COMMAND.md)。

本机已安装的用户，更新仓库后先关闭游戏，重新运行 `python tools/install.py`。然后双击 **start-vietnam.cmd**，从**新游戏**进入1965剧本；0.3和原版存档不兼容新增势力。

第一次安装需要本机游戏、Python 3.10+ 和联网下载人物资源：

    python -m pip install -r requirements.txt
    python tools/install.py

自动识别失败时：

    python tools/install.py --game "PATH TO Hearts of Iron IV"

启动入口自动挂载、启用、启动，并检查游戏日志中的越南地图和1965日期。桌面快捷方式可指向 start-vietnam.cmd。

`manage-mod.cmd` 是可选管理菜单：Mount只注册，Enable才写入启用列表；Disable恢复此前选择，Unmount取消注册并保留文件。6是启用并启动。注册名 **Vietnam 1965 Public**；本项目的旧注册项会移到用户配置目录的 v65-registration-backup，防止重复名称干扰加载。

## 0.6 测试版：十四年的战争与地方社会

1965—1979年的架空叙事框架：七个开局可玩势力，四个可选自治军区，共411项国策、64项自定义国家精神。新增165项按1968、1971、1974、1977、1979开放的长期国策；各阶段的军事优先、社会治理路线互斥，替换前期政策国家精神。参谋、训练、通信情报、后勤与军需合同可建设为五级机构，升级替换旧级，避免一次性奖励耗尽后无事可做。

- **柬埔寨内战**：柬埔寨王国 KHM 与红色高棉 RKH 是两个真实交战国家，各有领土、军队、人物与国策。此1965开局为小说启发的架空安排。政府对越南保持独立外交，国内战争不再自动关闭其秘密后方；共和剧情可改名为高棉共和国并由朗诺执政。
- **南越军区化**：西贡玩家在决议中确认下放西原、湄公河、东南、富国岛。各军区经数日交接成为有本地部队的自治附属政权，自行处理治安，可接手扮演、接受中央援助，忠诚足够后协商整合。归仁与岘港原有势力继续存在。
- **剧情情报**：线人、截报、村庄协商与请愿决议直接影响情报储备、叛乱压力和民心，无需创建原版情报机构。地方AI会花自己的政治点处理治安；压力过高会生成真实解放阵线部队。
- **人物与选择**：23组原创场景，每组有两种选择和45天后的差异回信。良民证、日海军需、撤军仓库、岛上自治、西原撤退、总统府双重命令、难民与战后行政均进入剧情。选择改变机构、民心、派系依赖、疲劳和关系；朴世诚关系影响联合政府谈判。未分发小说正文。
- **国家精神**：民心、派系依赖与战争疲劳持续产生不同精神。1979年有回顾和继续战争或尝试停战的选择；不会按年份强制推进地图、自动吞并南方或保证任何一方胜利。

新增叙事文件有75个事件定义，其中23个为后台转送事件；可见内容为46个场景及回信、5个阶段简报和1个尾声。这是借鉴TNO叙事方向的第一轮实现，尚不等同于TNO规模的完整视觉小说；没有复制其界面、美术或剧本。

请使用**新游戏的1965剧本**测试本版。旧存档不会重跑领土、人物和开局战争初始化。

## 战争与政变

- **北方对峙**：洞海、广治有4级工事；南北双方有防御准备及正面进攻惩罚。它是可被突破的阵地战，不是禁止交火的硬锁。
- **南方敌后**：解放阵线从金瓯出发，并在邦美蜀、西宁和美萩建立真实的孤立武装据点。它与北越结盟，但有自己的领袖、军队和国策。
- **胡志明小道**：北越维护通道，解放阵线积累组织能力；双方玩家可组织后方行动。AI解放阵线会自行使用准备。袭击从仍由西贡或自治军区控制的候选省份选择，改变省份控制并生成真实部队，冷却35天。南方联盟可以截断通道与组织准备。
- **战败引发政变**：广治或顺化落入北越，或芽庄与大叻同时落入解放阵线，触发前线败局、政治冲击和追责事件。没有战败就不能发动首都政变。
- **首都政治点博弈**：花政治点争取西宁、边和、头顿、美萩驻军。三处支持足够则和平夺权，一至两处支持引发西贡—头顿内战，无支持则失败。全国戒严降低支持流失，广治代表的非军事区除外。
- **朴世诚可直接扮演**：开局在归仁拥有部队、领地、原创领袖头像。可经营地方，或在政府战败后脱离联盟并进军西贡，形成第三条战线。韩国本土没有加入地图。

## 人物和素材

本地安装需要下载成功才会报告完成，避免再次出现启用后仍是通用头像的情况。来源与许可边界见 [THIRD_PARTY.md](THIRD_PARTY.md)。

## 验证与制作

    python tools/test_campaign.py
    python tools/test_mount.py
    python tools/campaign_smoke_test.py

真实引擎测试验证六国军队、国策、人物、后方据点、战败前禁用政变、战败后危机、戒严例外、政变三结果、小道生成部队和朴世诚独立干预。不操作桌面界面；运行前需关闭游戏。结果摘要为 public-test-summary.json。

作者可用 `python tools/rebuild_campaign.py` 重建内容。国策图标直接引用本机钢丝自带的绘制素材，无需下载字体或将原版美术上传仓库。安装玩家不需要执行内容生成器。

0.4实测：29项机制断言和24项一个月自然推演断言通过，模组运行错误0。自然推演中北部原防区保持，解放阵线存活并自动袭击；这不是多年战争平衡结论。国策布局经过坐标检查和素材预览，未使用桌面自动化做游戏界面截图核验。


## 0.5：联合政府与中立后方

- 撤下九种扁平盾牌图标，改为原版绘制图标，按军事、情报、军工、外交等内容绑定。
- 朴世诚新增六项联合政府国策。影响力至少5点、双方仍结盟且控制归仁和西贡时，可以花100政治点谈判，也可完成末端国策提出议定书。西贡可接受或拒绝；拒绝后90天内不能再提。
- 接受后，朴的领土、部队和人物合并到南越。朴世诚玩家自动转为控制南越；南越玩家继续控制原国家。阮文绍在台前，朴通过国家精神提高政治点、组织度与生产效率，同时降低稳定度。45天后军区会要求补偿或人事妥协。双方都由玩家控制时禁用合并。
- 柬埔寨可默许秘密基地，保持中立、不加入北方联盟。控制桔井与腊塔纳基里时，每月额外增加一级通道、一次南方动员和300支步枪；南方可提交证据施压，金边可承受损失或关闭基地。柬埔寨参战、基地州失守或主动关闭后，补给停止。
- 西原重镇失守触发90天交通混乱及政治危机；西贡失守时，若仍控制芹苴或富国岛，政府转移并获得继续抵抗精神。事件由实际地图控制触发，不按年份强制涂色。
- “太上皇”是小说中的权势描述；正式合并和中立柬埔寨是玩家可选的模组改编。未分发小说原文。

新增机制测试：在 PowerShell 中设置 `$env:V65_ROUTES_TEST='1'`，然后运行 `python tools/campaign_smoke_test.py`；结束后删除该环境变量，再运行普通机制测试。

地图阶段测试：设置 `$env:V65_STAGES_TEST='1'` 后运行同一测试脚本。它临时强制战败触发条件，检查交通混乱、政治危机、政府转移和继续抵抗效果，并在退出时恢复；不改地图控制权。真实地图条件由普通及自然推演测试加载。每次只设置一种测试模式。真人玩家自动接手国家的界面流程尚未实测。

0.5验证：29项原有机制、30项合并与中立后方、23项战败事件效果、24项一个月自然推演断言通过，四组模组运行错误均为0。另通过5项静态回归及挂载/恢复测试。自然推演不是多年平衡结论；真人接管国家的界面流程未实测。
