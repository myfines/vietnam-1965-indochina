# 私人财富与跨区人脉：机制参考

另查看了 [HOI4DEV 的高堡奇驹公开示例](https://github.com/Magolor/hoi4dev/blob/main/docs/zh/3.%E7%A4%BA%E4%BE%8B-PIHC2%E6%A8%A1%E7%BB%84.md)：这是虚构IP改编的开发示例，采用内容数据与分阶段生成脚本分离的组织方式。本项目保留自己的生成器，将章节场景、角色路线和图标题材分别落成数据，再统一构建与验证；没有引入它的世界设定或复制人物、美术。小说章节对应的可玩取舍见下文及源码章号。

## 目标与边界

这套机制把朴世诚个人的财富、享受和地区人脉与越南政权的领土归属分开。`SVN.v65_private_wealth` 与 `SVN.v65_private_comfort` 是长期锚点；朴系控制的个人网络可落在 `PKS`（朴世诚在野/卫队阶段）或被其接管的 `SVN`。各 `v65_network_<tag>` 关系值限定在 0–100，关系代表能否找到愿意接电话、调仓库、介绍军官的人，不等于该地区归顺中央。

本机制对应小说里朴世诚的跨区经营和个人享受：第307章富国岛的产业、人口与华人派系基础；第313章太极天炉需要军区配合；第327–330章战后援助与军火采购牵动派系；第333–345章游击政变、登陆筹备和军校建设；第351–364章头顿登陆、特工破坏与战线反复；第357章朴要求高文园结束休养回到前线；第417章私宅、第422–425章情人节宴饮、挑选女伴、朴世诚裸身后安排宴会、女仆代送咖啡等私生活桥段。适配时保留黑色幽默和利益交易的结构，改写对话与具体叙述，不复制小说文本或资源。

## 原生玩法结构

- **锚点不随政权切换丢失**：私产和享受写在 SVN 的持久变量上；朴系切换焦点树、调动驻地或完成合并后仍沿用同一本账。地区网络保留各自变量，不在 annex/transfer 时自动合并成领土或忠诚度。
- **先提议，后由对象表态**：朴系 `v65_open_contact_DNM` 设置待处理标记并向 DNM 发事件；目标通过自己的选项接受或拒绝。`v65_accept_contact_DNM` 必须在 DNM 国家作用域、待处理旗标存在且 `v65_park_partner_DNM` 成立时运行；立即调用可用于原生测试，正常游玩则由目标事件选择。接受给 DNM 20 政治点，并给 SVN 的 `v65_network_DNM` 加20；拒绝不改关系，提案活动费不退。
- **投资是双边收益**：达到关系与私产门槛后，朴系可以租用 DNM 仓库。支出从 SVN 私产锚点扣除；朴系 ROOT 与 DNM 各获得90天补给消耗减益；DNM地方动荡降低，关系也增加。双方效果分别在各自国家作用域结算，避免只给发起方加成。
- **关系带来持续分红，也会衰退**：每月结算时，对仍存在、条件合格且关系至少50的伙伴，SVN 私产增加1；每月衰退1点；当该关系不再满足伙伴条件时额外衰退5点，战时断交因此会更快。伙伴筛选必须检查国家存在、首都仍由其控制，以及朴系和伙伴之间处于和平状态；不因高关系让敌国也支付分红。每日/每月循环需使用旗标、日期窗口或唯一触发点，避免同日重复结算。
- **享受是花钱换短暂喘息**：周末决议花10私产，享受加15、政治点加15，并给朴系45天参谋/招待处精神。它有90天重启间隔和私产可用条件。事件文案体现副官、行程和招待处替司令挡杂事；不把消费写成无条件国家奖励。
- **富国岛转为地方自治后，起义回调仍需尊重控制权**：SVN 释放 PHQ 时先验证状态31和361仍在中央控制；PHQ 的 `v65_regional_outbreak` 在自身国家作用域执行时，不得让 FNL 仅凭旧中央脚本夺走 PHQ 的361省。回调检查 PHQ 拥有状态31并控制361，且 FNL 并未夺控该省。

## 事件、国策与可重复决议的原生参考

开源模组的资料适合借鉴作用域与节奏，不适合照搬剧情、美术或本地化。以下均是项目自身发布的脚本/维护资料：

- Kaiserreich 的 [on_actions 参考表](https://github.com/Kaiserreich/Kaiserreich-HOI4/blob/master/common/on_actions/_documentation.md)列有启动、日常、月度、战争关系、宣战、和平、吞并、释放等回调。其 [中国 on_actions 脚本](https://github.com/Kaiserreich/Kaiserreich-HOI4/blob/master/common/on_actions/on_actions_China.txt)展示按国家和战争/投降情境触发国家事件的做法。这里采用原生日常/每月机制更新账本，用国家事件让目标自己接受关系提案；一次性全局旗标和提案待处理旗标分别防止整段测试重跑与过期提案被接受。
- Kaiserreich 的 [通用国策树](https://github.com/Kaiserreich/Kaiserreich-HOI4/blob/master/common/national_focus/00%20Default%20focus.txt)展示 `prerequisite`、`available_if_capitulated`、`completion_reward` 等国策门控结构。适配到朴系路线时，国策负责解锁网络能力（如人脉、军需合同、军区干预），具体重复经营则留给决议；不要用国策重复发放可刷取的关系奖励。
- Kaiserreich 的 [KMT 决议脚本](https://github.com/Kaiserreich/Kaiserreich-HOI4/blob/master/common/decisions/01%20KMT%20decisions.txt)展示决议的可用条件、完成效果、移除效果和重启间隔等实践。此机制把每个地区的联络和仓库操作拆成有关系门槛、政治点/私产成本、90天重启间隔的决议，避免一键重复提款。
- EaW 的 [官方发布记录](https://github.com/EaW-Team/equestria_dev/releases)持续记录国家路线、国策绕过条件和重复决议等调整，可作为大规模模组维护路线门槛的实践参考；此处只借鉴按国家路线拆阶段、维护条件的方式，不挪用其世界观或资产。

## 阶段门控与章节映射

| 叙事段落 | 模组实现 |
|---|---|
| 1975撤退后，朴仍经营军头与富国岛关系（第307、313、327–330章） | 建立私人账本与关系变量；不同军区可接受、拒绝、借仓或参与军需采购；军区自治仍由原有忠诚与控制系统计算。 |
| 杨、高政变与第一游击行动（第330–342章） | 事件目标选择决定关系收益；若目标拒绝或朴的网络不足，不改变控制权，保留交涉失败后果。 |
| 军校和头顿登陆（第343–357章） | 国策解锁训练/海外联络阶段；关系足够后以决议租借仓库，双方暂时改善补给，允许登陆准备继续推进。 |
| 富国岛特区与朴个人享受（第307、357、417、422–425章） | PHQ 释放使用原有地区/起义回调；另用90天周期的周末决议把享受做成私产消耗和短期政治回报。 |
| 韩国政局冲击，朴离开越南（第365–386章） | 朴系操作主体和焦点树改变，但 SVN 财富、享受与地区人脉变量保留；友好关系随时间或交战衰退，避免个人网络变成永久免费资源。 |

## Probe 覆盖

`tools/story_revision_probe.py` 按项目的 `build(check, begin, end)` 格式输出原生 `on_actions` 脚本，检查：初始锚点与关系变量、朴系提议和 DNM 目标接受后的双边收益、军需站的私产支出/双方补给效果/地方动荡下降、关系门槛和不存在伙伴的分红过滤、已有 SVN–FNL 敌对关系不产生伙伴分红、周末决议的消费和享受/政治点/精神回报、PHQ释放后继续控制361，以及完成朴系合并后 SVN 私人锚点保留。

探针刻意不创建新战争；敌对过滤复用战役已有的 SVN–FNL 战争，并用伙伴筛选和分红结果验证。不在它运行时强行改变战争状态或战区归属。若开局脚本改动导致 PHQ 已释放或 SVN–FNL 关系变化，应更新探针前置状态，不能用新增宣战来让断言通过。

## 调整提示

脚本接口以 `tools/build_personal_network.py` 的实现为准：关系变量目前覆盖 SVN、DNM、HLC、MKG、BHD、PHQ、KHM；`v65_private_holiday` 的 ROOT 是朴系操作主体（PKS，或接管后持有 `v65_park_shadow_ruler` 的 SVN），财富/享受从 SVN 锚点扣加；仓库支出同样锚定 SVN。事件选择必须在目标国作用域处理接受/拒绝，调用时间与全局待办旗标要保持一致。
