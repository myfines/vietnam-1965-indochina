# 小说剧情点与指挥玩法

依据：已经保存的前、中、后段阅读笔记及十四年剧情骨架。本次没有重新通读小说。以下是分段整理，不冒充426章全部逐章核对；日期、编号冲突按笔记保留疑点。小说情节与可选玩法分开处理。

## 指挥模型

- 韩国本土与驻越上级：决定增援、撤军、职务和外部保护。
- 朴系集团：以直属部队、军需渠道、代理军和私人联系人扩权；前期培养势力，后期争夺南越实际中央。
- 南越中央：掌握名义任命、军区划分和军饷。威望不是国家稳定度，也不是某一军区忠诚。
- 军区：各自掌握地区与部队。中央威望低且当地忠诚低，才进入拒令；之后可以逼宫或起兵。
- 临时配属：应区别于永久转移国土；尚未实现单位级指挥链，不宣称现有脚本完整复现小说编制。

## 本轮已接入

1. 中央威望初始55；首都失守、已触发的前线溃败持续削弱威望，补发军饷可以恢复。
2. 四个新军区可分别设立；设立后，中央可将自己完整控制的南方州逐块划归该军区。首都25不在划转列表内。初次设立仍使用既有预设辖区，未实现自由绘制初始边界。
3. 威望低于30且军区忠诚低于25时可拒令。新设军区以指挥协定和共同阵营维持隶属关系，在引擎中不再创建外交傀儡；军区可要求中央让步，也可解除协定、退出共同战争和同盟后起兵。旧存档的外交傀儡过渡仍未验证。
4. 朴可经营人脉、扩充实际直属部队、用补给与部队关系换取影响力；6点人脉、5点影响力且中央威望低于40时，可要求接管。接受后沿用已实现的南越标签合并和太上皇精神；拒绝不会自动吞并。
5. 23段事件正文改成短摘要，46段后续回信缩短；保留已有选择效果。
